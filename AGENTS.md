# Contexto para Agentes de IA — AutoPYME

## Descripción del Proyecto
AutoPYME es una plataforma de automatización con IA para PYMEs argentinas. Incluye un bot de demo en Telegram ("Pimienta") y esta landing page promocional.

## Enlaces Principales
- Landing en vivo: https://autopymeia.netlify.app/
- Demo Telegram: https://t.me/Autopim_bot

## Instrucciones para el Agente
- Mantener un tono cercano, claro y orientado al mercado PYME argentino.
- Toda modificación en el frontend debe priorizar diseño responsive y tiempos rápidos de carga.
